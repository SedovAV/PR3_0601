# PR3_0601

## Однослойный перцептрон

### Цель работы

* Знакомство с базовой моделью нейронной сети
* Реализация алгоритма обучения перцептрона и убедиться, что однослойный перцептрон эффективен только для линейно разделимых задач

### 1. Теоретические сведения

Однослойный перцептрон — простейшая модель нейронной сети, состоящая из входного слоя и одного выходного нейрона.
